# BRUSH & SMILE

A Next.js storefront starter with two sample toothbrush SKUs.

## Run locally
1. Install Node.js (https://nodejs.org/)
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Visit http://localhost:3000

## Deploy
Push the project to GitHub, import the repository in Vercel, and deploy.

## Google Sheets
The `google-apps-script/Code.gs` file is a starter endpoint only. The live order + inventory workflow is not connected yet. Configure and test Apps Script before accepting real orders.
